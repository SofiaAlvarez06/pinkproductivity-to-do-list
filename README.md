# To-Do List Site 💗

A simple and aesthetic to-do list built with HTML, CSS and JavaScript.

## ✨ Features
- Add tasks
- Mark tasks as completed
- Progress bar tracking
- Start screen and navigation

## 💻 Technologies
- HTML
- CSS
- JavaScript
